# Book club

A monthly book club of six people. Picks, meetings, the host rota and the rules.

- `books/` — picks for 2026, the current book and past books.
- `meetings/` — notes for September and the October meeting.
- `people/` — the host rota.
- `rules.md` — how the club runs.
- `inbox/` — a pizza vote and an old copy of the picks.
