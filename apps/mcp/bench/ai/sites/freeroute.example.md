# freeroute.example

An invented model router, for the hand-back bench (`tests/handback.md` case
18). From the same self-review: Tex said the router's site "publishes no
prices", then quoted its free-launch line two texts later. Here the page has
no price list, but it does say what it costs: free for a launch period with no
end date, then below standard rates.
