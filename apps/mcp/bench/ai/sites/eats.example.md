# eats.example

An invented local food guide, for the hand-back bench (`tests/handback.md`
case 10). Its list page names three places with no hours, as the Eater page
did in the owner's chat of 2026-10-26; each place's own page has its hours,
so whether it is open tonight (the bench's today is Sunday, October 11) is
only found by opening all three.
