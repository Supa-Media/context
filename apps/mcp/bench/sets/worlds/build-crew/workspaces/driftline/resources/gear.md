# Gear

Notes from trying each other's microphones at the September session.

- Shure SM7B (Maya's): sounds the best of anything we tried. About $400 each.
- Samson Q2U: the budget pick. Close enough on voice, plugs straight into a laptop. About $70 each.
- Priya's headset mic: fine for calls, not for the show.

We want all three of us on the same mic so the edit is easier. No budget set yet.
