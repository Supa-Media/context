# One folder per built-in role is locked, and a name may not twin its sibling

Decided by the owner, 2026-10-14, after Tex made `projects` beside `Projects` in a personal workspace. Both folders were locked as built-in, so the empty duplicate could not be deleted, and the bucket had happily taken two names that read as one.

**Only the folder playing a role is protected.** `isProtectedFolder` (`packages/shared/src/folderRoles.cjs`) locks the folder `rolesIn` files into, which is the first by name among the root's folders claiming that role, and treats any other folder claiming it as ordinary: it can be renamed, moved into the real one, trashed or deleted. When it is gone, the one left is the role's folder again. The root is read as the caller sees it, so a role-mate they cannot see leaves the visible folder locked (the safe side), and a role nobody plays yet is locked by name whether or not it exists. Convex (`assertNotProtectedFolder`, `lib/fileOps/nameTwins.ts`), the gateway (`protectedFolderRefusal`, `apps/mcp/src/tree/twins.js`) and the file menu (`isBuiltInRow`, given the root's names) all ask it.

**A new name may not twin a sibling.** Creating a folder or note, renaming or moving onto a name, is refused when that name differs from a sibling only by case (folded with `foldName`: NFC, lower case), and at the root when a new folder would take a role another folder already plays (`1-projects` beside `Projects`). The refusal names the path to use instead, so an agent's retry lands in the existing folder. A sibling the caller cannot see is never refused on, because the refusal would name it. Names are read from the Convex tree, never the bucket; a tree that cannot answer skips the check rather than blocking the write. Existing twins are left alone: nothing is renamed for anyone.

If this is reversed, `apps/convex/__tests__/fileOps/nameTwins.test.ts`, the duplicate cases in `apps/convex/__tests__/builtInFolders.test.ts`, `apps/mcp/test/nameTwins.test.mjs` and `apps/mobile/__tests__/fileMenu/editabilityAndTargets.test.ts` fail.
